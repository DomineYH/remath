# 오개념 교정·도달점·도움 요청은 서버 규칙 엔진이 판정한다

PRD 8절은 "서버가 오개념 교정 카운터와 도달 여부를 프롬프트에 주입한다"고만 하고 카운터를 **올리는 주체**는 비워 두었다. 목업(`engineTurn`)은 서버가 예비교사 발화를 **교정 키워드**로 매칭해 카운터를 올리고 망설임(h)·교정(c)·아하(aha) 대사를 그대로 낸다. 이 방식을 v1 판정 규칙으로 확정한다: 결정적이고 단위 테스트가 가능하며, MOCK_LLM과 실 LLM 경로가 **같은 상태 기계**를 공유한다. 분석 챗봇은 분류만 하고 진전 판정에는 관여하지 않는다(ADR-0001의 `[CLASSIFICATION]` 블록 고정 유지).

## 규칙(목업 `engineTurn` 이식)

한 턴의 서버 처리 순서. 위에서 먼저 맞는 것 하나만 적용하고, 멘토 트리거는 **턴당 최대 하나**다.

1. `END SESSION`(정확히 일치) → 세션 종료.
2. **도움 요청**(트리거 2): 챗봇 언어별 서버 상수 정규식(목업 `detectStd`/`detectEn`의 help 패턴)이 맞으면 학생 LLM을 호출하지 않고 고정 문구("음… 저 아직 생각 중이에요.")를 학생 발화로 내고 멘토 LLM을 호출한다(입력 t2). 분석 챗봇 분류는 그대로 수행한다.
3. **도달 후**: `goal_reached`면 카운터·트리거 판정 없이 학생 LLM만 호출한다(런타임 블록에 "도달점 도달"만 표시).
4. **주도권 빼앗기**(트리거 1): 분석 결과 레버리지가 `Taking Over`면 학생 지시 = 혼란 대사(`confused[n % len]`, n = 지금까지 트리거 1 횟수), 멘토 LLM 호출(입력 t1, ADR-0001·티켓 16).
5. **교정 진전**: 레버리지가 `Taking Over`가 아닌 모든 발화(분류 기준이 없으면 모든 발화)에 대해, 카운터 < 2인 오개념을 목록 순으로 보며 교정 키워드가 처음 맞는 하나만 카운터 +1. 1회차 지시 = h, 2회차 지시 = c. 모든 오개념이 2가 되면 `goal_reached = true`, 지시 = aha(비어 있으면 마지막 c), 멘토 LLM 호출(입력 t3, 트리거 3).
6. 어느 것도 아니면 지시 없음: 학생 LLM이 현재 오개념 상태를 유지한 채 질문받은 것만 답한다.

교정 키워드는 오개념마다 언어별 정규식 문자열 하나(`kw`, 대소문자 무시)이며, 정규식으로 해석되지 않으면 부분 문자열 포함으로 대신한다(목업 `kwTest`).

## 런타임 블록

컴파일 프롬프트(C11, 게시 시 고정) 뒤에 서버가 호출마다 덧붙이는 섹션. 플레이스홀더가 아니다.

```
========================================================
H) 이번 턴 (서버 주입)
========================================================
오개념 진행: 1) 교정됨  2) 망설임(1/2)  3) 미교정(0/2)
도달점: 미도달
이번 턴 지시: 반드시 다음 취지로, 네 말투로 답하십시오 — "<h | c | aha | confused 대사>"
```

지시가 없으면 마지막 줄은 "이번 턴 지시: 없음. 현재 오개념 상태를 유지하고 질문받은 것만 답하십시오."가 된다. 지시는 **서버가 구조화된 값**(`{kind, text}`)으로 결정하고 블록은 그 렌더링이다. MOCK_LLM 학생 어댑터는 지시 텍스트를 그대로 돌려주므로 목업과 같은 대사가 나온다. 지시를 어댑터 인터페이스에 어떻게 전달하는지는 "공급자 어댑터 인터페이스·MOCK_LLM 어댑터 계약 초안"에서 정한다.

## Consequences

- 세션 상태로 오개념별 카운터(`mis: int[]`)와 `goal_reached`를 서버가 저장한다. 혼란 대사·도달 후 대사의 회전 인덱스는 저장하지 않고 `turns` 집계로 유도한다. 컬럼 형태는 "DB 마이그레이션 초안"에서 정한다.
- 도움 요청 정규식은 시나리오 데이터가 아니라 서버 상수(ko/en)다. 위자드에 새 필드가 생기지 않고 분류 기준이 없는 시나리오에서도 트리거 2가 동작한다.
- 키워드가 없는 좋은 발문은 진전을 만들지 못한다(알려진 한계). 분석 챗봇이 "오개념 N을 겨냥함"을 함께 돌려주는 (B)안으로 올리려면 `[CLASSIFICATION]` JSON에 키를 추가하면 되며, 서버 파서는 미지 키를 무시하므로 지금은 필드를 선언하지 않는다.
- 멘토 LLM은 트리거 3종 모두에서 호출된다(티켓 16, ADR-0001 개정). 도달 후에는 주도권 빼앗기 트리거가 더 발생하지 않는다(목업과 동일).
- 아하 턴 지시는 aha 한 줄이다(#68): c를 겹쳐 넣으면 학생이 같은 뜻의 두 문장을 빈 줄로 나눠 잇고, aha가 이미 마지막 교정 내용을 담는다.
- 근거 티켓: [오개념 교정·도달 판정 주체 결정](https://github.com/DomineYH/remath/issues/6).
